# Shorts Blocker

Android-приложение (Android 10–16), которое:
- закрывает плеер **YouTube Shorts** (обычные видео YouTube работают);
- закрывает просмотр **Instagram Reels** (лента, сторис, директ работают);
- не даёт открыть **TikTok**: сразу возвращает на домашний экран.

Работает через службу специальных возможностей (Accessibility): видит экран только этих
трёх приложений, ничего не сохраняет и никуда не отправляет. Интернет-разрешения у приложения нет.

## Установка APK
1. Скачайте `ShortsBlocker.apk` со страницы [Releases](https://github.com/Anton-Onskul/shorts_blocker/releases/latest) и откройте его на телефоне. Разрешите установку из этого источника.
2. Откройте Shorts Blocker → «Открыть «Специальные возможности»» → Shorts Blocker → включить.
3. Если на Android 13+ переключатель серый («Ограниченная настройка»):
   в приложении нажмите «Открыть «О приложении»» → ⋮ (справа сверху) → «Разрешить ограниченные настройки»,
   затем повторите шаг 2.
4. На Xiaomi/Huawei/Samsung отключите для приложения оптимизацию батареи, иначе система может выключать службу.

## Если Shorts/Reels снова открываются
Откройте Shorts Blocker → «Диагностика (2 минуты)» → откройте Shorts (вкладкой и из ленты) и Reels,
подержите каждый экран 5 секунд → вернитесь → «Отправить отчёт». По отчёту обновляются id в `ShortFormDetector.java`.

## Как устроено
- `app/src/main/java/com/shortsblock/app/core/` — логика без Android (что блокировать), покрыта тестами.
- `BlockerService.java` — служба специальных возможностей: перебирает окна YouTube/Instagram/TikTok, передаёт дерево экрана в `ShortFormDetector` и жмёт «Назад» (для TikTok — «Домой»). В режиме диагностики не блокирует, а записывает дампы экрана.
- `AndroidScreenNode.java` — адаптер дерева экрана Android для логики из `core/`.
- `ReportProvider.java` — отдаёт файл отчёта диагностики в «Поделиться».
- `MainActivity.java` — экран со статусом и переключателем.

Плеер определяется по семействам id (`reel_player*`, `reel_watch*`, `shorts_player*`, `clips_viewer*` и др.)
и по выбранной вкладке «Shorts» / «Reels».
Если YouTube или Instagram после обновления переименуют их, блокировка перестанет срабатывать —
тогда списки в `ShortFormDetector.java` нужно обновить.

## Тесты
```
./run_tests.sh
```
100 проверок логики на обычной JVM (Android не нужен). Подробности — `docs/SPEC.md`.

## Сборка
- **GitHub Actions** (`.github/workflows/build.yml`): на каждый push — тесты и сборка APK (артефакт);
  на тег `v*` — релиз. Ключ подписи берётся из секретов `KEYSTORE_BASE64` и `KEYSTORE_PASSWORD`, в репозитории его нет.
- **Android Studio**: открыть папку проекта (Gradle-файлы приложены).
- **Без Gradle** (так собран приложенный APK):
  `BT=<sdk>/build-tools/34.0.4 ANDROID_JAR=<sdk>/platforms/android-33/android.jar ./build_apk.sh`
  Скрипт прогоняет тесты, компилирует с `-Werror`, собирает и подписывает APK ключом `signing/shortsblocker.jks`
  (`signing/` в `.gitignore`). Новые версии подписывайте тем же ключом, иначе обновление поверх не установится.
